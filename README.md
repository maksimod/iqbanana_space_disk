# IQBanana Disk - Система управления NFS дисками

## Обзор системы

IQBanana Disk представляет собой систему для автоматического монтирования и управления NFS-дисками между серверами. Система включает в себя:

- Автоматическое обнаружение доступных NFS-дисков на сервере
- Монтирование дисков с оптимальными параметрами
- Автоматическое добавление и удаление монтирований при изменении набора дисков
- Мониторинг состояния монтирований и автовосстановление
- Создание резервных копий

## Автоматическая настройка с Ansible

Система использует Ansible для автоматической настройки и развертывания. Следуйте инструкциям ниже для полной настройки.

### Требования

- Ubuntu/Debian (тестировалось на Ubuntu 24.04)
- Доступ к серверу NFS (IP: 192.168.0.104)
- Права sudo

### Быстрая настройка (автоматически)

Для автоматической настройки всей системы выполните:

```bash
cd ansible-debian-setup
sudo ./auto-configure.sh setup-all
```

Этот скрипт выполнит следующие действия:
1. Установит Ansible, если он отсутствует
2. Настроит файлы конфигурации Ansible
3. Настроит NFS клиент и смонтирует доступные диски
4. Настроит систему резервного копирования
5. Создаст первый полный бэкап системы

### Настройка только NFS

Если вам нужно настроить только монтирование NFS дисков:

```bash
cd ansible-debian-setup
sudo ./auto-configure.sh setup-nfs
```

### Ручное управление NFS дисками

После настройки вы можете вручную управлять NFS дисками с помощью скрипта `unified-nfs-manager.sh`:

```bash
# Монтирование всех доступных дисков
sudo ./unified-nfs-manager.sh mount

# Проверка статуса монтирований
sudo ./unified-nfs-manager.sh status

# Оптимизация параметров NFS
sudo ./unified-nfs-manager.sh optimize

# Перемонтирование с новыми параметрами
sudo ./unified-nfs-manager.sh remount
```

## Автоматическое обнаружение изменений в наборе дисков

Система настроена на автоматическое обнаружение изменений в наборе доступных дисков. Если на NFS сервере будут добавлены новые диски или удалены существующие, система автоматически обновит монтирования благодаря:

1. Регулярной проверке через Watchdog (каждые 10 минут)
2. Автоматической очистке неактуальных монтирований
3. Добавлению новых доступных дисков

Вы можете изменить интервал проверки в файле `/etc/systemd/system/nfs-watchdog.timer`.

## Устранение неполадок

Если у вас возникли проблемы с монтированием дисков:

1. Проверьте статус монтирований:
   ```bash
   sudo ./unified-nfs-manager.sh status
   ```

2. Проверьте логи:
   ```bash
   sudo tail -f /var/log/mount-nfs.log
   sudo tail -f /var/log/nfs-watchdog.log
   ```

3. Перезапустите сервисы:
   ```bash
   sudo systemctl restart mount-nfs.service
   sudo systemctl restart nfs-watchdog.timer
   ```

4. Принудительное перемонтирование всех дисков:
   ```bash
   sudo ./unified-nfs-manager.sh mount --force
   ```

## Дополнительная информация

Все скрипты хранятся в каталоге `ansible-debian-setup`. Основные компоненты:

- `unified-nfs-manager.sh` - универсальный скрипт для управления NFS
- `auto-configure.sh` - скрипт автоматической настройки с Ansible
- `roles/sync/` - роль Ansible для настройки NFS клиента
- `roles/nfs/` - роль Ansible для настройки NFS сервера
- `roles/backup/` - роль Ansible для настройки резервного копирования

# Файловый менеджер дисков

Веб-приложение для управления файлами на смонтированных дисках сервера.

## Особенности

- Просмотр списка доступных дисков с информацией о занятом и свободном пространстве
- Навигация по папкам
- Загрузка файлов
- Скачивание файлов и папок (папки автоматически архивируются)
- Удаление файлов и папок
- Создание новых папок
- Адаптивный интерфейс

## Структура проекта

### Frontend (React)

- Модульная структура с разделением компонентов
- Оптимизированный CSS с использованием переменных
- Хуки для работы с API
- Вспомогательные утилиты для форматирования

### Backend (Node.js/Express)

- Модульная архитектура с разделением на маршруты и контроллеры
- Система логирования
- Обработка ошибок
- API для работы с файловой системой

## Установка и запуск

### Через Docker (рекомендуется)

1. Убедитесь, что Docker и Docker Compose установлены
2. Клонируйте репозиторий
3. Запустите контейнеры:

```
docker-compose up -d
```

### Ручная установка

#### Backend

```
cd backend
npm install
npm start
```

#### Frontend

```
cd frontend
npm install
npm start
```

## API эндпоинты

- `GET /api/disks` - получение списка дисков
- `GET /api/disks/:disk/files?path=<path>` - получение списка файлов
- `POST /api/disks/:disk/upload?path=<path>` - загрузка файла
- `DELETE /api/disks/:disk/files` - удаление файла или папки
- `POST /api/disks/:disk/createFolder` - создание новой папки
- `GET /api/disks/:disk/download?path=<path>` - скачивание файла или папки

## Требования к системе

- Node.js 14+
- Смонтированные диски в директориях:
  - `/mnt/disk_sda1`
  - `/mnt/disk_sdb1`
  - `/mnt/disk_sdb5`
