# IQBanana Disk System

Система для управления дисками, сетевым хранилищем и резервным копированием.

## Установка и настройка

### Установка зависимостей

```bash
# Установка зависимостей MongoDB и Mongoose
cd backend
npm install mongoose mongodb --save
```

### Настройка MongoDB

```bash
# Запустите скрипт настройки MongoDB (потребуются права суперпользователя)
sudo ./scripts/setup_mongodb.sh
```

Скрипт установит MongoDB 6.0 для Debian 12 или предложит альтернативное решение, если установка не удастся.

## Настройка резервного копирования

### Настройка автоматических бэкапов

```bash
# Запуск настройки резервного копирования
./backup/auto_backup.sh

# Для немедленного запуска резервного копирования
./backup/auto_backup.sh now
```

Скрипт `auto_backup.sh` настраивает резервное копирование на сервере:
1. Копирует необходимые скрипты (`make_backup.sh` и `setup_backup_cron.sh`) на сервер
2. Настраивает cron-задание для автоматического создания бэкапов по расписанию
3. Отправляет статусы бэкапов на API сервер для отображения в веб-интерфейсе

## Статусы резервного копирования

В веб-интерфейсе отображаются следующие статусы бэкапов:

- **PROCESSING** - Процесс резервного копирования запущен
- **SUCCESS** - Резервное копирование успешно завершено
- **ERROR** - Произошла ошибка при резервном копировании

## Настройка API ключа

API ключ для резервного копирования берется из файла `/backend/.env` или используется значение по умолчанию.

Для изменения API ключа добавьте или измените строку в файле `.env`:

```
API_KEY=ваш-секретный-ключ
```

## Конфигурация бэкапов

Настройки резервного копирования находятся в файле `/backup/backup_config.sh`:

- `BACKUP_SERVER` - IP-адрес сервера для резервного копирования
- `CLIENT_IP` - IP-адрес клиента
- `BACKUP_FREQUENCY` - Частота создания бэкапов (daily, weekly, monthly)
- `MAX_BACKUPS` - Максимальное количество сохраняемых бэкапов

## Мониторинг

Статусы бэкапов записываются в лог-файл и отображаются в веб-интерфейсе в карточках дисков.

## Маршруты API

### Бэкапы

- `POST /api/system/backup-status` - Обновление статуса бэкапа
