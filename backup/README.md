# Система автоматического бэкапа дисков с Borg Backup

Данная система предназначена для автоматического бэкапа дисков на целевом сервере с использованием Borg Backup.

## Особенности

- Полный бэкап указанного диска
- Автоматическая установка Borg Backup при необходимости
- Настройка регулярных бэкапов (ежечасно/ежедневно/еженедельно/ежемесячно)
- Автоматическая очистка старых бэкапов
- Шифрование бэкапов
- Возможность восстановления бэкапов

## Файлы системы

- `backup_config.sh` - конфигурационный файл с настройками бэкапа
- `backup_functions.sh` - библиотека функций для бэкапа
- `setup_backup.sh` - скрипт для настройки системы бэкапа
- `restore_backup.sh` - скрипт для восстановления данных из бэкапа
- `backup.log` - лог-файл с информацией о выполнении бэкапов

## Настройка

1. Отредактируйте файл `backup_config.sh`:
   - Укажите сервер, на котором нужно настроить бэкап (`BACKUP_SERVER`)
   - Укажите диск источник, с которого будет браться бэкап (`SOURCE_DISK`)
   - Укажите диск назначения, на который будет сохраняться бэкап (`TARGET_DISK`)
   - Задайте частоту автоматических бэкапов (`BACKUP_FREQUENCY`)
   - Укажите максимальное количество хранимых бэкапов (`MAX_BACKUPS`)

2. Запустите скрипт настройки:
   ```
   chmod +x setup_backup.sh
   ./setup_backup.sh
   ```

Скрипт выполнит следующие действия:
- Проверит доступность сервера
- Установит Borg Backup, если он не установлен
- Подготовит диск назначения
- Инициализирует репозиторий Borg
- Настроит автоматические бэкапы в соответствии с заданной частотой

## Восстановление данных

Для восстановления данных используйте скрипт `restore_backup.sh`:

```
chmod +x restore_backup.sh
./restore_backup.sh [имя_бэкапа]
```

Если имя бэкапа не указано, скрипт выведет список доступных бэкапов и предложит выбрать один из них.

**ВНИМАНИЕ!** Восстановление полностью перезапишет содержимое диска источника. Все данные на диске будут потеряны и заменены данными из бэкапа.

## Дополнительные возможности

- Редактирование пользовательских скриптов, которые будут выполняться до и после бэкапа (`PRE_BACKUP_SCRIPT` и `POST_BACKUP_SCRIPT`)
- Изменение пароля шифрования в файле `.env` (переменная `BORG_PASSPHRASE`) или в конфигурационном файле (`DEFAULT_BORG_PASSPHRASE`)

## Требования

- Доступ по SSH к целевому серверу
- Права root на целевом сервере
- Доступные диски source и target на целевом сервере
